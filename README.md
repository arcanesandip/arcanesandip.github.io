# ⚡ THE LAST PORTFOLIO

A self-correcting, low-maintenance system. Built to be the last one I ever have to manually update.

### ⚙️ Why it's the last one:

*   **Auto-Sync:** `scanner.py` tracks my GitHub activity in real-time.
*   **Zero-Touch:** GitHub Actions handles the backend processing and deployment.
*   **Decoupled:** Content is pulled from repo metadata, not hard-coded HTML.

### 🚀 Stack

*   **Engine:** Python / GitHub API
*   **Pipeline:** GitHub Actions (Cron @ 00:00)
*   **Storage:** `projects.json`
